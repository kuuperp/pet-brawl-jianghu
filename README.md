## v2.5.0 人物与兵器精修

- 四位主角进一步精修：眼白、虹膜、瞳孔和眉眼比例，连续曲面额带，立体领襟与滚边、刺绣、金属腰扣、护腕缝线；企鹅羽翼徽、熊猫木珠与玉饰、猫侠皮带及连续曲面尾巴、玉兔花扣各有造型。
- 剑、刀、匕首、枪、戟、斧、锤、杖、弓、扇、盾与法器采用新的锻造网格。刀刃有真实厚度、锋刃斜面、剑脊和沟槽，弯刀、重剑与枪尖有不同轮廓；弓臂为连续曲线，扇面有立体折褶，丝带为连续双面曲面。
- 手柄增加缠绳、箍环、尾饰，护手、铆钉、嵌宝与阴刻线由实体几何构成。部分趣味兵器补充竹叶、鳞片、锅铆钉、琴孔与调音钮等细节，保留原有趣味造型。
- 材质增加随物体移动的程序细纹，区分皮毛、织物、皮革、拉丝金属、木纹与玉石；调整线性色彩照明和输出亮度，并加入金属的环境反光，弱化塑料质感。
- 角色与兵器图鉴提高绘制分辨率，按实际三维边界自动取景；略微转动展示模型以显露侧面的厚度，同时放大图鉴与详情中的模型。战斗继续保持正面平视擂台、双方侧身相对。
- 共享骨架、动作命中锚点、全屏战斗特效，以及v2.4.0的经验、数值平衡和无奖励提前切磋规则保持兼容。模型和材质随站点提供，无外部资源依赖。

## v2.4.0 成长平衡与提前切磋

- 经验按双方等级的绝对差衰减：0–5级100%，6–10级70%，11–20级30%，21–30级10%，超过30级2%；高打低、低打高均适用，向下取整，可获得0经验。
- 经验基础量随对手等级和类型计算。擂台热身、标准、困难对手约为同级升级需求的16%、20%、24%；主线普通、精英、伏击、试炼、小Boss、章节Boss分别为34%、42%、36%、38%、55%、75%。重游先乘65%，失败乘20%，再应用单场上限，最后乘等级差倍率并向下取整。非首通胜利单场上限为当前升级需求的30%，正式首通85%，失败8%；满级不再加经验。
- 等级属性增量在30级后按86%、80级后按70%计算；攻击、防御、敏捷的成长系数调整。敌人的基础成长也同步调整。修炼在20、60、120次后按属性逐段降低收益，后期花费增长；页面显示下一次实际基础提升。已有等级、经验、修炼次数、物品、CDK固定加成和主线进度保留，新公式统一计算派生属性。
- 所有80个主线Boss可从地图提前切磋。未来普通关卡仍需顺序解锁。提前切磋无论胜负均无经验、铜钱、物品、升级或首通收益，不增加任务、胜负场次、声望或连胜，不推进主线；只保存切磋战报。
- 提前切磋不会消耗正式首通资格。主线抵达该Boss关后，重新击败它可正常领取奖励并推进一关；重复结算受原有幂等保护。
- 地图、擂台和结果面板使用同一份奖励规则，明确显示提前切磋、等级差衰减和重游收益。

## v2.3.0 主角重塑与全屏演出

- 重塑企鹅、熊猫、橘猫与玉兔：收小头部、雕塑面部与耳朵，加入虹膜、眼睑、手指、拇指、武靴与分层武服。四位主角各有配色、服装、配饰与轮廓，战斗仍侧身面向对手。
- 使用连续曲面网格制作头部、收腰衣身、袖筒、靴子及耳朵；布料有曲面起伏。皮毛、织物、皮革与金属使用不同粗糙度，高光、冷暖补光和轮廓光增强体积，角色脚下增加分层接触阴影。
- 交战时平视镜头适当靠近，让窄屏也能看清动作。动作轴心移至腰胯；拳脚增加发力后的惯性、回收与再蓄力，出招加入胸腰转动、腕部翻转、目光变化与衣摆跟随。共享骨架同时计算真实手脚和特效锚点，避免转身时特效脱离肢体。
- 战斗演出层扩展至整个浏览器视口，强招冲击环、光晕、放射线及透视碎片可以越过擂台与卡片边界；同时保留擂台内的实体三维刀光、元素招式和动态照明。

## v2.2.0 长擂台与随机换装

- 擂台横向长度增加70%，双方初始间距由6增加至11.6，普通近身攻击的接近距离超过原来的两倍。跑步增加步数和时长；交战时镜头保持平视，平移并靠近交战区域，收招后回到全景。
- 每件兵器在本场随机获得3、4或5次持械出手额度。用满后下次己方行动随机退场，投掷、丢弃各50%，随即取出下一件兵器；投掷和丢弃有各自的飞行表现。
- 命中与否都计一次，眩晕不计次，连击只计一次；缴械、抢夺和拾取保留每件兵器的已用次数和原额度，不会刷新同一件兵器的额度。
- 移除固定投掷/丢弃选择，改为自动随机；兵器栏、使用刻度、提示和战报显示各件实际额度。战后随身装备还原，旧存档继续兼容。

## 开发与发布

需要Node.js 22或更新版本，无运行依赖。

```sh
npm test
node scripts/stamp-release.mjs
```

`tests/v2-mainline.test.mjs` 覆盖Boss打断、二十种首领技能、阶段变化、章节方针、旧存档恢复及三维网格资产。有效兑换码相关的三项检查需要维护者设置 `CDK_TEST_CODE`，仓库只保存兑换码摘要。

当前原生浏览器画面、帧率和设备兼容性未进行实机检查。

Sites源码以 `dist/` 为发布目录。GitHub/Render副本将同一份 `dist/` 同步为 `public/`，Render仍发布 `public/`，无需新增运行服务或收费资源。

Render工作区：My Workspace；站点：`srv-db8ouiei0phs738gebig`；自动部署关闭，源码同步后手动触发部署。

更换域名或设备时，在旧地址设置中导出JSON，再到新地址导入。仓库早期 `review/` 下的v1.5离线文件不代表当前v2.0线上版本。
