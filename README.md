## 开发与发布

需要Node.js 22或更新版本，无运行依赖。

```sh
npm test
node scripts/stamp-release.mjs
```

`tests/v2-mainline.test.mjs` 覆盖Boss打断、二十种首领技能、阶段变化、章节方针、旧存档恢复及三维网格资产。有效兑换码相关的三项检查需要维护者设置 `CDK_TEST_CODE`，仓库只保存兑换码摘要。

当前原生浏览器画面、帧率和设备兼容性未进行实机检查。

Sites源码以 `dist/` 为发布目录。GitHub/Render副本将同一份 `dist/` 同步为 `public/`，Render仍发布 `public/`，无需新增运行服务或收费资源。

Render工作区：My Workspace；站点：`srv-db8ouiei0phs738gebig`；自动部署关闭，源码同步后手动触发部署。

更换域名或设备时，在旧地址设置中导出JSON，再到新地址导入。仓库早期 `review/` 下的v1.5离线文件不代表当前v2.0线上版本。
