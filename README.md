# 宠斗江湖

当前线上地址：https://pet-brawl-jianghu.onrender.com

## v1.5.0 待确认更新

本分支为待确认稿，尚未发布。线上仍为 v1.4.0。用户确认后再合并至 main 并手动部署 Render。

- 16 套空手绝学的独立图形、配色和施法特效，4 种宠物专属绝招。
- 聚气法阵、拳风刀光、命中冲击波、粒子、地面震波、飞行尾迹、护盾与恢复特效；20 种被动功法的触发印记。
- 与人物动作共用唯一战斗时钟，支持暂停、续播、1–3 倍速、切后台暂停和简化动画；取消时清理所有特效。
- 设置和存档区域新增 CDK 兑换。限定护身神器“太初·无极天印”仅经兑换获得，每份存档一次，自动装备，可卸下。
- 装备时攻击、防御、闪避值各 +50,000；不影响敏捷先手或暴击。闪避值参与概率计算，普通攻击仍有至少 5% 命中率，必中绝招保持原规则。
- 神器为独立护身装备，不进商店或掉落池、不占兵器槽，不改变原有兵器五次行动后投掷/丢弃规则。
- 本机单机 CDK 校验，不是服务端账户权益系统，无法防止玩家修改客户端或本地存档，也不提供跨存档全局单次兑换。
- 地图、200 关主线、普通武器池和原存档键保持不变。

## 检查与试玩

Node.js 22 或更新版本，无需安装运行依赖。

```sh
npm test
node scripts/build-review.mjs
```

需要有效兑换码的两项单元测试在缺少 `CDK_TEST_CODE` 时跳过；维护者用私下保存的有效兑换码设置此环境变量后运行完整检查。代码仓库只保存兑换码摘要，不保存明文兑换码。

已执行 61 项检查，全部通过且未跳过，包括实际控制器兑换流程、存档往返、神器实战加成和特效渲染/时钟检查。原地图文件哈希检查通过。

`review/playable-preview.html` 可下载后在浏览器打开：包含完整游戏和“查看全部功法特效”演武入口。演武场不读写存档。试玩版本不是线上版本。

当前环境缺少浏览器控制，未进行真实浏览器画面及帧率实测；已使用真实特效绘制函数和原 SVG 人物姿态进行原生 Canvas 画面检查，并运行 DOM 控制器检查。原生 Canvas 图不是浏览器截图。
