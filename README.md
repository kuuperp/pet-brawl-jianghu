## CDK 兼容修复

兑换码未更换。移除对 Web Crypto、TextEncoder 和安全上下文的依赖，改用便携 SHA-256 校验；接受复制时的空格、换行、全角字符和中英文横线。新增标准 SHA-256 向量与多块边界对照、无 Web Crypto 环境的正确/错误/重复兑换检查。6 项兑换专项检查通过，并在禁用 Web Crypto 的离线整包上通过控制器兑换、导入导出及装备切换检查。仍未上线，需用户确认。

## CDK 点击响应修复

兑换区域不再使用原生 HTML 表单。兑换按钮通过现有点击事件直接调用兑换，输入框回车也直接调用；不依赖嵌入式容器的表单提交权限。点击立即显示校验状态并锁定按钮，空值、错误码和重复兑换显示原因；成功后弹出神器领取与属性提升窗口，区分已保存和需要导出备份。新增只触发点击、不触发表单提交的控制器检查，覆盖立即反馈、重复点击、成功弹窗、存档和回车错误提示。此检查是控制器/DOM 适配器检查，不是真实浏览器自动化。
