## v2.1.0 侧身对战与豪华特效

- 镜头继续正面平视擂台，双方改为侧身面向对手。头脸、躯干、护甲和兵器朝内，手脚关节沿擂台平面出招，兼容画面也采用侧脸。
- 普攻增加实体弧形光刃和多层命中冲击。功法按火焰、冰晶、风暴、岩石、花雨、星阵等类型呈现不同的立体轨迹、碎片和法阵，绝招及Boss技能增强范围与密度。
- 修正刀光过细、效果被人物遮挡的问题。特效锚点跟随真实手脚关节，主要冲击位于人物前方，并加入加色发光材质。
- 蓄力压暗环境，彩色点光源照亮人物和擂台；命中加入全场色光、冲击光晕、放射线、轻微推进与震动。血条和伤害数字保留清晰层级。
- 特效、光影、镜头、飘字和实际扣血共用暂停、倍速及后台暂停时钟，结束或跳过时清理。闪避不产生命中震动；简化模式保留基本光刃和冲击，不启用全屏光影和震动。

## v2.0.1 战斗画面修复

- 伤害、格挡、回血及反伤跟随每次命中，二连击分别显示真实分段数值；复活、阶段变化和战报不会提前揭示结果。
- 飘字创建时隐藏，使用固定节点、相机投影坐标和一次完整的停留、上浮、淡出过程。高倍速保留至少600毫秒的显示时间，暂停、简化动画和后台暂停共用战斗时钟。
- 改为居中、正面平视的透视相机。缩短擂台纵深，统一左右站位，调整台沿与台阶；血条区域与战斗场景分开，大Boss按视口留出头顶空间。
- 投掷轨迹、兵器交接、地面兵器和实际扣血使用相同时间点；兼容画面也同步采用新的数值时序。

## 开发与发布

需要Node.js 22或更新版本，无运行依赖。

```sh
npm test
node scripts/stamp-release.mjs
```

`tests/v2-mainline.test.mjs` 覆盖Boss打断、二十种首领技能、阶段变化、章节方针、旧存档恢复及三维网格资产。有效兑换码相关的三项检查需要维护者设置 `CDK_TEST_CODE`，仓库只保存兑换码摘要。

当前原生浏览器画面、帧率和设备兼容性未进行实机检查。

Sites源码以 `dist/` 为发布目录。GitHub/Render副本将同一份 `dist/` 同步为 `public/`，Render仍发布 `public/`，无需新增运行服务或收费资源。

Render工作区：My Workspace；站点：`srv-db8ouiei0phs738gebig`；自动部署关闭，源码同步后手动触发部署。

更换域名或设备时，在旧地址设置中导出JSON，再到新地址导入。仓库早期 `review/` 下的v1.5离线文件不代表当前v2.0线上版本。
